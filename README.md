# Rahul Sharma's Portfolio

My personal portfolio website — a single-page app showcasing my projects, skills, and background.

**Live site:** [rahulsharma-cs.site](https://rahulsharma-cs.site)

## Built With

- **Next.js 16** (App Router)
- **React 19** + **TypeScript**
- **Tailwind CSS**
- **Motion** (Framer Motion's successor) for animations
- **Magic UI**-style dock and meteors

## Running Locally

```bash
npm install
npm run dev
```

Other scripts: `npm run build`, `npm run start`, `npm run lint`, `npm run typecheck`.

## Structure

All code lives in `src/`: one route (`src/app`), section components (`src/components/sections`), site chrome (`src/components/layout`), reusable UI (`src/components/ui`). Personal data — name, email, socials, projects, skills — is centralized in `src/lib/data.ts`.
